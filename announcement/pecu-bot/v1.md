# 📢 **PeculiarLads Bot — 5-Day Development Update**

We've been cooking behind the scenes over the last few days, and here's everything that's been added!

## 🆕 New Commands

### 👤 Character Management

> Register and manage your characters directly from Discord.

* `/character add`
* `/character classes`
* `/character nstg`

### 🛡️ Scammer Database

> Help keep the community safe.

* `/scammer add`
* `/scammer list`

### 📋 Member Information

* `/profile` — View your own or another member's registered characters.
* `/roster` — Browse the guild roster.

### ⏰ Staff Utilities

* `/schedule` — Schedule recurring announcements *(Officer/Admin only).*

---

## 🚀 Website Signup Is No Longer Required

You can now join the guild **entirely through Discord.**

Simply run:

`/character add`

Fill in your:

* Class
* NSTG
* IGN

…and you're all set!

No passwords.
No waiting for manual approval.

> 💡 **Not sure of your class or NSTG ID?** Run `/character classes` and `/character nstg` first — they'll list every valid ID so you can plug the right numbers into `/character add`.

---

## ⚡ Faster Website Applications

If you still prefer applying through the website, the process is now much smoother.

As long as you're **not listed in the scammer database**, you'll automatically receive a Discord invite as soon as your application is submitted.

No more waiting for an admin to manually approve and send an invite.

---

## 🔗 Automatic Discord Linking

Using either:

* `/character add`
* `/profile`

will now automatically link your Discord account to your profile.

`/sync` is still available if you ever need to relink manually, but for most users, it shouldn't be necessary anymore.

---

## ✅ Onboarding Is Still Required

Before using the bot, new members must complete onboarding by either:

* Posting their application in the onboarding channel, **or**
* Applying through the website.

Once onboarding is complete, all bot commands will become available.

---

## 💬 Mention **@pecu-pecu**

You can now simply mention **@pecu-pecu** anywhere in the server and it'll respond.

No more needing to use `/talk` every time.
